ตั้งค่า Supabase Backend

ระบบสามารถทำงานได้ทันทีด้วย Local Database จำลอง หรือเชื่อมต่อกับ Supabase คลาวด์จริงของคุณ

คำแนะนำ:
1. นำไฟล์ supabase_schema.sql ในโปรเจกต์นี้ไปรันใน Supabase SQL Editor
2. คัดลอก Project URL และ anon key จากหน้า Settings -> API มาวาง
3. หากยังไม่มีบัญชี Supabase แอปจะทำงานด้วยโหมด LocalStorage อัตโนมัติ 100%!
