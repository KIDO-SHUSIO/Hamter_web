## 🎯 จุดเด่น & การตอบโจทย์เงื่อนไข

### 1. หน้า Landing Page แนะนำแอปพลิเคชันสุดดึงดูด & Pricing Tiers
- **Hero & Value Proposition**: ชูจุดเด่น "เที่ยวแล้วสร้างรายได้ ได้เงินคืน & ส่วนลด ฿10,000+" เพื่อกระตุ้น Conversion Rate
- **Interactive Pricing Cards**:
  - **Free Explorer (฿0)**: เข้าถึงแผนที่พื้นฐาน แต่ถูกล็อกพิกัดลับและไม่ได้รับเงินคืน
  - **Pro Traveler (฿199/เดือน - ยอดนิยม 🔥)**: ปลดล็อก GPS แม่นยำ, เควสรับคูปองเงินสด, ลีดเดอร์บอร์ด, ส่วนลด 15%
  - **VIP Elite Voyager (฿499/เดือน - คุ้มค่าสูงสุด 👑)**: ปลดล็อกพิกัดลับ Unseen Thailand 77 จังหวัด, ส่วนลด 50%, AI ไกด์ส่วนตัว, ประกันการเดินทางฟรี

### 2. หน้า Payment Gateway จำลอง & การแสดงผล 'ชำระเงินสำเร็จ'
- ป๊อปอัป Gateway รองรับ **พร้อมเพย์ (QR PromptPay)** พร้อมเลขออเดอร์, ราคาสมาชิก, และเวลานับถอยหลังจริง
- รองรับแท็บ **บัตรเครดิต/เดบิต** พร้อมฟอร์มที่สมจริง
- เมื่อกด **"ยืนยันการชำระเงิน"**:
  - จำลองการประมวลผลและการบันทึกธุรกรรมลงใน Supabase / LocalStorage
  - แสดงผลแอนิเมชันเฉลิมฉลองด้วย **พลุกระดาษ Confetti**
  - แสดงผลโมดอล **"ชำระเงินสำเร็จ! (Payment Successful)"** พร้อมใบเสร็จอิเล็กทรอนิกส์ (Receipt Ref, ยอดเงิน, แพ็กเกจ)
  - ปรับระดับสมาชิกของผู้ใช้ (User Tier) เป็น **PRO** หรือ **VIP** อัตโนมัติทันที

### 3. แดชบอร์ดตามภาพร่าง Wireframe ทั้ง 4 หน้าจอ (100% Match)

| หน้าจอตามภาพร่าง | การทำงานในระบบ |
| :--- | :--- |
| **1. หน้าหลัก (แผนที่ GPS)** | - ช่องค้นหาตำแหน่ง (Search Bar)<br>- แผนที่อินเทอร์แอ็กทีฟ Leaflet พร้อมหมุดจุดท่องเที่ยวทั่วไทย และพิกัดลับ VIP ที่ล็อกไว้สำหรับสมาชิก Free<br>- แถบสถานะความเร็ว **"ความเร็ว km/h"** ด้านล่าง พร้อมเกจวัดความเร็วและปุ่มจำลองการเดินทาง (เดิน 5 km/h, ปั่น 22 km/h, ขับรถ 75 km/h) |
| **2. หน้า กิจกรรม** | - ภารกิจ 4 หมวดตรงตามไอคอน: **เดินเท้า (Walking)**, **ปั่นจักรยาน (Cycling)**, **ขับรถยนต์ (Roadtrip)**, **มอเตอร์ไซค์ (Motorbike)**<br>- แถบความคืบหน้าระยะทางสะสมจริง และปุ่มแลกรับคูปองเงินสด/เหรียญรางวัล |
| **3. หน้า ลีดเดอร์บอร์ด** | - **โพเดียม Top 3** (อันดับ 1 มงกุฎทองคำ, อันดับ 2 เหรียญเงิน, อันดับ 3 เหรียญทองแดง) แสดงรูปโปรไฟล์และระยะทาง km<br>- ลิสต์อันดับ **4, 5, 6** แสดงชื่อ ฉายานักเดินทาง และระยะทาง km<br>- การ์ดแสดงอันดับของตัวผู้ใช้งานเอง |
| **4. หน้า บัญชี** | - แสดงรูปโปรไฟล์, ชื่อบัญชี, และป้ายสถานะระดับสมาชิก (FREE / PRO / VIP)<br>- สรุปผลประโยชน์ตัวเงิน (เงินที่ประหยัดได้ ฿, Travel Coins)<br>- เมนูดูประวัติใบเสร็จการชำระเงิน และปุ่มตั้งค่า Supabase Backend |

## 🗄️ การตั้งค่า Supabase Backend

1. เข้าไปยังแดชบอร์ดของ [Supabase](https://supabase.com) และสร้างโปรเจกต์ใหม่
2. ไปที่เมนู **SQL Editor** แล้วคัดลอกเนื้อหาทั้งหมดในไฟล์ [`supabase_schema.sql`](file:///c:/Users/KIDO2/OneDrive/Desktop/New%20folder%20(4)/supabase_schema.sql) ไปวางและกด **Run**
3. ไปที่ **Project Settings -> API** เพื่อคัดลอก:
   - **Project URL**
   - **anon / public key**
4. ในหน้าเว็บแอปพลิเคชัน ให้กดปุ่ม **Supabase** ที่แถบเมนูด้านบน นำ URL และ Key มาวาง แล้วกด **"บันทึกการเชื่อมต่อ"**
5. ระบบจะทำการเชื่อมโยงข้อมูลและบันทึกประวัติการสมัครสมาชิกลงสู่ Cloud Database แบบเรียลไทม์ทันที!
*(หากยังไม่ได้เชื่อมต่อ แอปมีระบบ Local Storage สำรองทำให้ทดสอบฟังก์ชันทั้งหมดได้ทันที 100%)*
